# OI生涯回忆录

一个模拟信息学竞赛(OI)选手从新手到高手成长历程的HTML5游戏。

![游戏截图](assets/images/screenshot.png)

## 游戏特色

- 🎮 **模拟成长**：体验从编程新手到OI高手的完整成长路径
- 📚 **学习系统**：学习各种算法和数据结构，提升能力
- 💻 **刷题练习**：解决不同难度的编程题目
- 🏆 **比赛竞技**：参加各级别竞赛，争夺名次
- 🎯 **成就系统**：解锁各种成就，记录你的OI生涯
- 📊 **属性成长**：算法能力、代码能力、调试能力等多维度成长
